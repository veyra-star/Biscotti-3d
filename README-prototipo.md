# Biscotti — prototipo 01

Esperienza 3D scroll-driven con Three.js. Demo con cinque biscotti, sollevamento, esplosione in ingredienti, focus e ricomposizione.

## Avvio locale

```bash
python3 -m http.server 8000
```

Aprire http://localhost:8000.
